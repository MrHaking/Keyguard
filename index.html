Возможности

Один центр управления

KEYGUARD объединяет управление клавиатурой, KIOSK-режимом, макросами и системными функциями в едином интерфейсе.

⌨

Blocked Keys

Добавляйте отдельные клавиши и комбинации для блокировки в режиме защиты. Поддерживается в том числе клавиша Win.

▣

KIOSK Mode

Выбирайте запущенную программу и переводите её в управляемый полноэкранный режим с отдельной системой выхода.

◫

Все мониторы

Открывайте информационные полноэкранные окна на всех дисплеях и управляйте их закрытием через пароль или аварийный выход.

⚡

Macros & Actions

Создавайте макросы и Python Actions, запускайте их по комбинациям и смотрите вывод в отдельном терминале.

◉

Background Mode

KEYGUARD может запускаться вместе с Windows, работать в фоне и оставаться доступным через значок в системном трее.

⬡

Installer

Установщик добавляет программу в Windows, создаёт ярлыки, поддерживает удаление и может проверить наличие Python.

KIOSK без лишних шагов

Выберите запущенное приложение, запустите KIOSK и контролируйте выход через пароль и настроенную комбинацию.

✓Поддержка нескольких мониторов
✓Настраиваемая комбинация обычного выхода
✓Пароль и cooldown после нескольких ошибок
✓Фиксированный аварийный fail-safe

Блокировка клавиш

Создавайте собственный список запрещённых клавиш и комбинаций для KIOSK. Правила сохраняются и применяются при запуске режима.

✓Одиночные клавиши
✓Комбинации Ctrl / Alt / Shift / Win
✓Импорт правил из KeyGuard

Macros & Actions

KEYGUARD позволяет привязывать действия к комбинациям клавиш и запускать собственные Python Actions.

✓Action Library
✓Терминал вывода ошибок и print()
✓Установка библиотек при наличии Python

Работа в фоне

После входа в Windows KEYGUARD может стартовать автоматически и оставаться в системном трее без открытого главного окна.
